# SBOM проекта

SBOM (Software Bill of Materials) — машинно-читаемая опись компонентов
приложения. Она отвечает на вопрос: «Из каких библиотек и версий собран этот
проект?» SBOM не является отчётом об уязвимостях: аудит отвечает, опасен ли
компонент, а SBOM фиксирует сам состав.

Workflow `Generate SBOM` создаёт два отдельных CycloneDX JSON-артефакта:

| Артефакт | Источник | Что входит |
| --- | --- | --- |
| `python-runtime-sbom-<commit>` | Изолированное Python-окружение с установкой `-e .` без группы `dev` | Backend runtime-зависимости и их граф |
| `frontend-runtime-sbom-<commit>` | `frontend/package-lock.json` | Frontend runtime-зависимости без `devDependencies` |

Генерация выполняется для pull request, после изменения `main` и вручную.
Артефакты доступны на странице соответствующего запуска GitHub Actions и
удаляются через 7 дней.

## Защита публикации

- Workflow имеет только право `contents: read`.
- Checkout не сохраняет GitHub credentials.
- Внешние Actions закреплены полными commit SHA.
- Генератор Python SBOM установлен отдельно и не попадает в опись приложения.
- Результат публикуется только после проверки формата, корневого компонента,
  числа компонентов и ссылочной целостности графа зависимостей.
- Валидатор отклоняет credential URL, чувствительные query-параметры и локальные
  пути сборочной машины.
- SBOM содержит имена, версии, лицензии, Package URL и связи зависимостей, но не
  исходный код, значения переменных окружения или SourceCraft-токены.

Репозиторий приватный, поэтому скачивать артефакты могут только пользователи с
доступом к его GitHub Actions. При публикации репозитория политика доступа к
SBOM должна быть пересмотрена отдельно.

## Ограничения

Python-проект пока не имеет lock-файла. Поэтому Python SBOM фиксирует версии,
которые resolver выбрал именно во время конкретного запуска, а не гарантирует
повторяемость будущего разрешения зависимостей. Frontend SBOM воспроизводимее,
потому что строится из `package-lock.json`.

Эти два файла описывают зависимости приложений. Они не заменяют container SBOM:
пакеты базовых Docker-образов и операционной системы в них не перечислены.
