# CI/CD-анализатор

Модуль `backend/app/analyzers/cicd.py` оценивает надёжность CI/CD по готовому
снимку запусков. Он не делает HTTP-запросов и не читает системное время: период
всегда приходит в `AnalysisContext`. Благодаря этому один и тот же снимок
воспроизводимо даёт один и тот же результат.

## Вход

Поставщик получает `RepositoryRef` текущего запуска и возвращает `CicdFacts`.
Факт `CiRunFact` содержит только `slug`, статус, тип события и `created_at`.
Полные логи задач, пользователь, текст ошибки и токены в факты не входят.

| Состояние фактов | Результат |
| --- | --- |
| `runs=None` или source error | `unavailable` без score |
| Неполная страница | `insufficient_sample` без score |
| Пустая история, только ручные, незавершённые или менее 5 итоговых запусков | `insufficient_sample` без score |
| Не менее 5 автоматических запусков с итогом | `measured`, score = доля `success` |

`CicdFacts` не допускает одновременно данные и source error, повторные `slug`
или пометку неполноты без собранных запусков. Неподдерживаемый статус, тип
события или дата без часового пояса также отклоняются до расчёта Score.

## Подключение SourceCraft

PR №13 добавляет `SourceCraftCicdClient`, который безопасно получает
пагинированные `SourceCraftCiRun`. После его принятия отдельный адаптер должен
для каждого `SourceCraftCiRun` создать `CiRunFact(slug, status, event_type,
created_at)` и передать все факты в `build_facts`. Ошибка клиента должна стать
`build_facts(None, source_error=...)`, а не нулевой успешностью.

Затем `make_analyzer(provider)` оборачивается в
`AnalyzerRegistration("cicd", ...)` при сборке общего запуска. До этого этапа
модуль не зарегистрирован в production dispatcher и не делает вид, что
анализирует реальный репозиторий самостоятельно.

В наблюдённом ответе SourceCraft API поле `id` запуска может быть пустым, но
`slug` содержит номер запуска. Поэтому именно `slug` используется для защиты
от двойного учёта. Автоматическая оценка не раскрывает slug или детали job в
отчёте.

## Проверка

```sh
python -m pytest backend/tests/test_cicd_analyzer.py -q
```

Тесты проверяют формулу, границы периода, отменённые и ручные запуски,
недостаточную выборку, неполную историю, типы входов, дубли, исключение
поставщика и отмену выполнения. Все данные синтетические.
